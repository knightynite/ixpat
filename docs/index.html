iXpat

Haptic feedback, an Action Ring, kinetic scrolling and force click for the Microsoft Surface Mouse (2nd Edition) on macOS. The feel the mouse has on Windows, and more, from a free and open source menu bar app.

Download for macOS
v0.1.0 macOS 14+ | Apple Silicon | 3.6 MB
or build from source:
$ git clone https://github.com/knightynite/Thrum.git && cd Thrum && ./build.sh

Quick Install

1Open DMG, drag to Apps
2Launch from the menu bar
3Allow Input Monitoring & Accessibility
Permissions: haptics and pointer settings work with none. Input Monitoring reads the mouse's own reports; Accessibility is for kinetic scrolling, the action button, menu and selection ticks. No kernel extension, no private framework.

What you get

FeatureDetails
HapticsThe mouse's own eight waveforms and five strengths, per event: clicks, wheel detents, menu highlights, text selection, screen edges, drag & drop, window tiling, app switches
ScrollingDynamic ratchet (firm when slow, light when fast, a bump on reverse, free-spin on a flick) and kinetic scrolling with momentum and acceleration sliders
Force clickPress and hold for Look Up and link previews, with a pulse when it engages
Action buttonPress, double-press and hold each mapped to an action: Action Ring, Mission Control, Spotlight, screenshot, lock, media, an app, a shortcut, a shell command
Action RingRadial menu under the pointer with up to eight chambers and a detent per chamber
GesturesHold the action button and move: volume, brightness, tracks and desktops, with the pointer held still
Per appProfiles per app, pointer speed and scrolling for this mouse only, and a loopback bridge so plugins can request a pulse

Notes

  • Drives the mouse's standard HID haptic controller from user space; the trackpad is untouched
  • Click and wheel feel presets, plus a live schematic that shows every report and pulse
  • Settings and logs live in ~/Library/Application Support/Thrum
  • A Windows counterpart and firmware updates are planned: read the plan
